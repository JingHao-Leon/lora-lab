Q: what is lora => A: lora adds small trainable matrices to a frozen model
Q: what is qlora => A: qlora quantizes the base model to four bit then trains lora
Q: why freeze weights => A: frozen weights keep old knowledge and cut memory for gradients
Q: what is rank => A: rank is the width of the low rank update matrices
Q: what is alpha => A: alpha scales the update and is often set to two times rank
Q: how to merge => A: add the product of b and a times scaling to the base weight
Q: what is nf4 => A: nf4 is a four bit float format with sixteen optimal levels
Q: what is sft => A: sft fine tunes a model on instruction answer pairs
Q: what is a prompt mask => A: a prompt mask hides prompt tokens from the loss
Q: what is packing => A: packing joins short samples into one fixed length block
Q: what is warmup => A: warmup ramps the learning rate up before decaying it
Q: what is grad clip => A: grad clip rescales gradients when their norm explodes
Q: what is an adapter => A: an adapter is a small module trained beside frozen weights
Q: what is a checkpoint => A: a checkpoint saves model weights so training can resume
Q: what is beam search => A: beam search keeps several candidates and picks the best
Q: what is greedy decoding => A: greedy decoding always picks the most likely token
Q: what is a token => A: a token is a piece of text the model reads or writes
Q: what is a logits => A: logits are the raw scores for every token in the vocab
Q: what is cross entropy => A: cross entropy measures how wrong the prediction was
Q: what is an epoch => A: an epoch is one full pass over the training data
